🕯️ Séance

Talk to your dead code.

Every codebase is haunted by functions nobody calls, exports nobody imports, and imports nobody uses. Séance finds them, lays them out as a graveyard, and lets you Bury them or Resurrect them. Your code never leaves your machine — except when you ask it to fetch a public GitHub repo.

Summon the dead

Public repos only. Fetched through the unauthenticated GitHub API (60 requests/hour).

Files are read locally in your browser. Nothing is uploaded anywhere.
